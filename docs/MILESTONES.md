# Milestones

- **M0 — Foundation:** scope, CI, publishing contract, syllabus and toolchain plan.
- **M1 — Native basics:** toolchain, ABI, Amiga types and basic DOS interaction.
- **M2 — Exec:** memory, tasks, signals and scheduling concepts.
- **M3 — Messaging:** ports, messages and synchronization.
- **M4 — DOS:** filesystem and process-oriented programming.
- **M5 — Devices:** I/O requests and asynchronous I/O.
- **M6 — Application APIs:** Intuition, events and reusable libraries.
- **M7 — Automation/networking:** ARexx and network programming where supported.
- **M8 — Debugging and machine connection:** defensive C, diagnostics and 68k/ABI.
- **M9 — Complete course:** capstone, emulator qualification, AmigaGuide/book/web release.

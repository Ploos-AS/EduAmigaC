# Publishing contract

The canonical educational source lives in `course/`.

Planned outputs:

- web/HTML
- PDF/book
- EPUB when supported
- **AmigaGuide** as a first-class target

AmigaGuide output should remain usable on classic systems: conservative markup, navigable nodes, useful cross-links, and examples that do not depend on web-only presentation.

Publishing uses the shared Ploos toolchain. Generated output is not canonical source.

# Definition of done

A chapter is complete only when its learning objectives, explanation, examples, exercises and checkpoint are present and reviewed.

For target-code chapters, documentation-only completion is insufficient. Applicable examples must reach the qualification level declared by that chapter or milestone:

- Q0 host validation
- Q1 m68k cross-build
- Q2 redistributable m68k runtime where compatible
- Q3 automated emulator/runtime integration
- Q4 real AmigaOS where claimed
- Q5 real hardware where claimed

Evidence is fail-closed: missing evidence means the level is not claimed. Q2/Q3 AROS results never substitute for Q4 AmigaOS evidence, and emulator results never substitute for Q5 hardware evidence.

Minimum CPU/OS requirements must be stated when above baseline. No proprietary ROM/OS/SDK material may enter the repository or distributable build artifacts.

Publishing qualification includes AmigaGuide for chapters included in an AmigaGuide release.

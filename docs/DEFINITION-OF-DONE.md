# Definition of done

A chapter is complete only when its learning objectives, explanation, examples, exercises and checkpoint are present and reviewed.

For target-code chapters, documentation-only completion is insufficient. Applicable examples must reach the declared qualification level: m68k build PASS and, where behavior can be exercised automatically, runtime PASS in the intended amiga-runtime profile.

Minimum CPU/OS requirements must be stated when above baseline. No proprietary ROM/OS/SDK material may enter the repository or build artifacts intended for redistribution.

Publishing qualification includes AmigaGuide for chapters included in an AmigaGuide release.

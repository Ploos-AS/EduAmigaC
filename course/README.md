# EduAmigaC course source

EduAmigaC assumes the core C knowledge taught by EduC and teaches native AmigaOS systems programming.

The course should connect C concepts to the Amiga execution model: Exec, DOS, libraries, devices, tasks/processes, signals, message ports and asynchronous I/O.

Examples should target real Amiga APIs and remain suitable for emulator qualification. Proprietary AmigaOS/Kickstart files must never be committed.

AmigaGuide is a first-class publishing target alongside web and book output.

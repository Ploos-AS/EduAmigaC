# EduAmigaC syllabus

1. Your first Amiga C program
2. Toolchain, ABI and executable model
3. Amiga types, headers and library calls
4. Exec fundamentals
5. Memory allocation and ownership
6. Tasks, processes and scheduling
7. Signals
8. Message ports and messages
9. DOS and filesystem programming
10. Devices and I/O requests
11. Asynchronous I/O
12. Intuition fundamentals
13. Events and input
14. Libraries and reusable interfaces
15. ARexx ports and automation
16. Networking where available
17. Defensive Amiga C
18. Debugging and diagnostics
19. C ↔ 68k: ABI, stack and generated assembly
20. Capstone: a native multitasking Amiga application

The course targets genuine Amiga programming concepts rather than treating AmigaOS as a themed C environment.
